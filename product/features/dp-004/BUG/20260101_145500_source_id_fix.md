# DP-004 Bug Fix: source_id and Directory Naming Issues

**Timestamp:** 2026-01-01 14:55:00 UTC
**Mesh Swarm Analysis:** Completed with path-analyzer, source-fixer agents

## Issues Identified

### Issue 1: source_id = "unknown-Mqtt" Instead of Stream Name

**Symptoms:**
- `source_id` field in Parquet files showed `unknown-Mqtt` or `unknown-Http`
- Should be `air-quality-Mqtt`, `nws-forecast-Http`, etc.

**Root Cause:**
In `source_manager.rs`, all three source types were created using `with_context()` which does NOT pass `stream_id`:

```rust
// BEFORE (incorrect)
MqttSource::with_context(config, parser, ndp_id, context)
HttpPollingSource::with_context(config, parser, ndp_id, context)
GenericHttpPollingSource::with_context(config, parser, ndp_id, context)
```

The `with_context()` method internally calls `with_raw_config(..., None, ...)` passing `None` for `stream_id`, causing `source_id()` to return `"unknown-{SourceType}"`.

**Fix Applied:**
Changed to use `with_raw_config()` with explicit `stream_id`:

```rust
// AFTER (correct)
MqttSource::with_raw_config(config, parser, Some(stream_id.clone()), ndp_id, context)
HttpPollingSource::with_raw_config(config, parser, Some(stream_id.clone()), ndp_id, context)
GenericHttpPollingSource::with_raw_config(config, parser, Some(stream_id.clone()), ndp_id, context)
```

**Files Changed:**
- `apps/air-quality-app/src/coordinator/source_manager.rs` (lines 425-431, 754-760, 825-831)

### Issue 2: Directory Named "unknown-Mqtt" Instead of Stream Name

**Symptoms:**
- Directories like `/data/raw/unknown-Mqtt/` created
- Should be `/data/raw/air-quality/`

**Root Cause:**
This was a cascading effect of Issue 1. When `source_id` was `"unknown-Mqtt"`, the directory was named accordingly.

**Status:** Fixed by Issue 1 resolution.

---

### Issue 3: Directory Includes Protocol Suffix

**Symptoms:**
- Even with correct stream_id, directories would be `/data/raw/air-quality-Mqtt/`
- Should be `/data/raw/air-quality/` (just the stream name)

**Root Cause:**
In `core/src/storage/parquet.rs`, the `raw_partition_path()` function used `source_id` directly:

```rust
// BEFORE (incorrect)
pub fn raw_partition_path(&self, source_id: &str, ...) -> PathBuf {
    self.base_path.join("raw").join(source_id)...  // Includes "-Mqtt" suffix
}
```

**Fix Applied:**
Added `extract_stream_id()` function to strip protocol suffix:

```rust
// AFTER (correct)
fn extract_stream_id(source_id: &str) -> &str {
    const SUFFIXES: &[&str] = &["-FileWatch", "-Webhook", "-HttpPoll", "-Http", "-Mqtt"];
    for suffix in SUFFIXES {
        if source_id.ends_with(suffix) {
            return &source_id[..source_id.len() - suffix.len()];
        }
    }
    source_id
}

pub fn raw_partition_path(&self, source_id: &str, ...) -> PathBuf {
    let stream_id = extract_stream_id(source_id);  // Extract stream name only
    self.base_path.join("raw").join(stream_id)...
}
```

**Files Changed:**
- `core/src/storage/parquet.rs` (lines 448-481, 1487-1518)

### Data Schema (Unchanged)

The Parquet schema remains:
- `timestamp` - Microseconds since epoch
- `source_id` - Full identifier with protocol (e.g., `air-quality-Mqtt`)
- `ndp_id` - Platform-assigned ID (e.g., `aq_airgradient_1`)
- `context` - JSON metadata
- `raw_payload` - Original JSON from source
